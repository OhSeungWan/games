クリアグリッド プライバシーポリシー

施行日：2026-10-02

このポリシーは、モバイルパズルアプリ「クリアグリッド」（以下「本アプリ」）が iOS と Android で個人情報をどのように取り扱うかを説明します。

概要

  • 本アプリ自体は個人情報を収集・送信しません。サーバー、アカウント、分析・クラッシュレポートのツールはありません。
  • 本アプリには広告があります。広告は Google Mobile Ads SDK が表示し、この SDK が下記のデータを処理します。
  • 広告の削除の購入が端末で確認されると、それ以降は広告 SDK を起動しません。

本アプリが自ら行うこと

  • 進行状況、記録、設定、ヒントの数、広告の間隔、購入状態はこの端末にのみ保存します。
  • このデータは iOS の iCloud・端末のバックアップと、Android のクラウドバックアップ・端末間の転送から除外されるため、バックアップによっても端末の外に出ません。
  • このポリシーや利用規約を開く前に、接続を確認するため ohseungwan.github.io の名前解決（DNS 参照）を行います。識別子や内容は送信しません。本アプリが自ら行うネットワーク通信はこれだけです。
  • このページと利用規約はブラウザで開きます。ページにはスクリプト、Cookie、トラッキングはありません。

広告と広告 SDK

本アプリは、Google が提供する Google Mobile Ads SDK と Google User Messaging Platform（UMP）SDK を使用します。これらの SDK は次のデータを収集・送信します。

  • 端末の識別子：広告識別子（iOS の IDFA、Android の広告 ID）とアプリセット ID
  • IP アドレスと、それから推定したおおよその位置情報
  • 広告データと製品の操作（アプリの起動、タップ、広告の表示など）
  • パフォーマンスデータ、クラッシュデータ、その他の診断データ

Google はこのデータを、広告の表示と測定、同意した場合のパーソナライズ広告、分析、不正防止に使用します。UMP SDK は、同意フォームを表示する必要があるかを判断するために、おおよその位置情報、パフォーマンス、操作のデータを使用します。データは送信中に暗号化されます。

UMP SDK は同意の選択を、Google Mobile Ads SDK は設定と識別子を端末に保存します。これらはアプリを削除すると消去されます。設定 → データをリセットでは消去されません。

広告リクエストは子ども向けとして扱われず、広告コンテンツのレーティングは最大 G です。

Google によるデータの取り扱いについては、Google プライバシーポリシーとGoogle のサービスを使用するサイトやアプリから収集した情報の Google による使用をご覧ください。

同意とトラッキング

  • 法律で同意が必要な地域では、起動時に Google の同意フォームを表示します。
  • iOS では、同意フォームの後に App Tracking Transparency（ATT）の許可を求めます。トラッキングを許可しない場合、広告 SDK は広告識別子を使用できません。

同意の変更と撤回

  • アプリ内：設定 → 広告のプライバシー設定。この項目は必要な地域でのみ表示されます。
  • iOS：端末の設定アプリで「プライバシーとセキュリティ」→「トラッキング」を開き、本アプリのトラッキングの許可をオフにします。
  • Android：端末の設定アプリで広告の設定（端末により「プライバシー」または「Google」の下）を開き、広告 ID をリセットまたは削除します。

広告の削除を購入した場合

広告の削除の購入が端末で確認されると、それ以降、本アプリは起動時に同意の手続きを省略し、広告 SDK を起動しません。それより前に送信されたデータ（再インストール後、購入を復元するまでを含む）は、上記の広告 SDK の項目に従います。

支払い

アプリ内課金は Apple（App Store）と Google（Google Play）が処理します。本アプリは支払い情報を受け取らず、広告の削除を所有しているかどうかだけを端末に保存します。

評価とレビュー

本アプリはストアの評価画面を表示することがあります。この画面は Apple と Google が表示・処理します。Android で入力した評価とレビューは Google Play にレビューとして投稿されます。本アプリは入力内容を受け取りません。

データの削除

本アプリが保存したデータを消すには、アプリの設定 → データをリセットを使うか、アプリを削除してください。Google が処理するデータは上記の Google のポリシーに従います。

子ども

本アプリは 13 歳未満の子どもを対象としていません。本アプリ自体は、子どもを含め誰の個人情報も収集しません。

ポリシーの変更

このポリシーを変更する場合は、新しい内容をこのページに掲載し、上記の施行日を更新します。
